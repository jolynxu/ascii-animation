# ascii-anim

moving ascii art 

## Animations

| name        | what it shows                                                   |
|-------------|-----------------------------------------------------------------|
| `starfield` | Stars flying toward you from the center of the screen           |
| `matrix`    | Green characters raining down the screen                        |
| `wave`      | A rolling ocean made of sine waves                              |
| `bounce`    | A ball bouncing off the edges with a fading trail               |
| `jellyfish` | A pulsing jellyfish in navy, light blue, purple and magenta     |
| `space`     | A spinning ringed planet, orbiting moon and shooting stars      |

## Run

```bash
python3 animate.py            # starfield (default)
python3 animate.py matrix     # digital rain
python3 animate.py wave       # ocean waves
python3 animate.py bounce     # bouncing ball
python3 animate.py jellyfish  # color-shifting jellyfish
python3 animate.py space      # ringed planet, moon and shooting stars
```

press `Ctrl+C` to quit. on Windows, use `python` instead of `python3`.

**Tip:** the animations look best in a large terminal window with a dark
background. Resize the window while one is running and it adjusts to fit.
